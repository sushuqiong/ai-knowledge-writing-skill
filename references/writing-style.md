# Public Explainer Style

- Write for the declared audience, not for an imagined reviewer.
- Put the answer near the beginning and context after it.
- Prefer one idea per paragraph and descriptive, non-clickbait headings.
- Use analogies to clarify mechanisms, then state where the analogy stops.
- Translate necessary terminology once; do not remove distinctions that matter.
- Use lively examples without manufacturing drama, authority, or certainty.
- Keep source notes separate from the reader-facing narrative unless attribution
  changes interpretation.
- End with a concrete takeaway, not a motivational slogan.
