# Privacy and Originality Guide

Use this file before publishing, pushing to a public repository, or turning private material into public text.

## Remove or Generalize

- local file paths
- user names, account IDs, emails, phone numbers, addresses, and personal identifiers
- tokens, keys, passwords, cookies, secrets, and credentials
- private URLs, internal systems, private screenshots, and unpublished data
- exact filenames that reveal private context
- confidential project names unless explicitly approved for publication
- local commit metadata that exposes a personal email or machine path
- private GitHub issues, branches, or release notes that were never meant for public reuse
- screenshots that show browser tabs, notifications, desktop clutter, or file explorers
- copy text that reveals a private workflow, account, or unpublished plan

## Safe Placeholders

Use generic placeholders:

- `[source]`
- `[topic]`
- `[document]`
- `[dataset]`
- `[repository]`
- `[private note]`
- `[example]`
- `[page]`
- `[lane]`
- `[prompt]`

## Originality Rules

- Extract high-level ideas, categories, and workflow patterns.
- Do not copy headings, slogans, screenshots, examples, or tutorial order.
- Do not imitate a source's sentence rhythm closely.
- Acknowledge inspiration when useful, but keep the new work independently written.
- If a source is copyrighted, quote only brief compliant excerpts and rely on summary.
- When inspired by a public repository or page layout, keep the structure generic and rewrite the wording from scratch.
- For demo pages and README files, do not mirror the source's copy blocks, button labels, or section order too closely.

## Public Claim Safety

- Mark uncertain claims as uncertain.
- Verify current facts when they may have changed.
- Avoid turning correlation, association, or AI-generated patterns into causal claims.
- For biomedical or clinical content, keep it as education or research support, not diagnosis or treatment advice.
- Before creating a public repository or Pages site, scan for private file paths, emails, tokens, and machine names one more time.
