# Public Writing Guide

Use this file for public explainers, WeChat/公众号 drafts, popular-science articles, learning notes, and educational copy.

## Reader-First Structure

Default article shape:

1. Title that names the topic plainly.
2. Opening that explains why the topic matters.
3. "What it is" section.
4. "How it works" or "basic workflow" section.
5. "Why it matters" or "where it is used" section.
6. Common mistakes, caveats, or limits.
7. One-sentence takeaway.

## Tone Rules

- Write for the stated audience.
- Prefer short paragraphs and concrete examples.
- Explain jargon at first use.
- Use analogies only when they clarify the mechanism.
- Avoid marketing exaggeration, fake certainty, and decorative filler.
- Keep medical, legal, and financial content cautious and non-advisory unless the user provides a different compliant context.

## Non-Copying Rewrite

- Keep public facts, but rebuild the article structure.
- Do not mirror the source's headings, slogans, examples, or sequence.
- Replace command-heavy material with conceptual explanation unless a tutorial is requested.
- For screenshots and external articles, avoid sentence-level paraphrase that follows the original too closely.

## Length Control

- If a word or character limit is given, write to that limit and verify it.
- For short public posts, prefer fewer sections with clearer transitions.
- If content is too long, cut examples before cutting definitions or caveats.
