# Security and Privacy Policy

## Report a vulnerability privately

Use GitHub private vulnerability reporting:

https://github.com/sushuqiong/ai-knowledge-writing-skill/security/advisories/new

Do not include credentials, private documents, patient or customer data,
personal records, or unpublished material in a public issue.

## Project boundary

This repository contains instructions and deterministic local file tools. It has
no backend, telemetry, account system, automatic upload, or mandatory model/API
connection. Host agents and office applications retain their own permission and
data-processing boundaries.

Security and privacy fixes apply to the latest release and `main`.
