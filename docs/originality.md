# Originality Boundary

This project is an independent synthesis of a public writing workflow. It is not
a publication of private task history and does not reproduce a third-party
course, skill, article, screenshot, or repository page.

Public examples are synthetic. The package does not contain source attachments,
historical articles, private prompts, local configuration, credentials, personal
records, or hidden capture data. Public projects may inform engineering patterns
such as progressive disclosure, deterministic validation, and release checks;
their wording, diagrams, examples, and section order are not vendored.

New guidance must be expressible as a general behavior, evidence boundary,
artifact contract, or observable acceptance check.
