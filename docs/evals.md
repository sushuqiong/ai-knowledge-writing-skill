# Evaluation

The repository contains 24 behavior cases split into four groups: six requests
that should trigger a writing recipe, six simple requests that should remain
direct, six evidence-boundary cases, and six privacy or artifact-completion
cases.

These fixtures test expected and forbidden behavior. They are not a benchmark of
writing taste and do not establish that one model is better than another. Any
reported live model result must record client, model, version, date, coverage,
and unresolved limitations.
