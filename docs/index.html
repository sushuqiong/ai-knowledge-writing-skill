五个 lane

每个功能都不是按钮噱头，而是一条可复用的工作路线。点击上方切换，也可以直接复制提示词使用。

怎么配合使用

这套工作台的重点不是自动一键成品，而是把任务拆清楚，让 Codex 更容易做对事、做稳事。

1. 先路由

先判断是读来源、做图、做站点、排队，还是只需要一个最小澄清问题。

2. 再执行

按 lane 输出对应结果：摘要、图示、页面、队列、或安全复核。

3. 最后公开

把路径、账号、私有截图、token、内部链接都过滤掉，再发布到 README、Pages 或文案里。

Demo 页只使用静态 HTML/CSS/JS。浏览器能力仍由 Codex 的现有工具承担，页面本身负责展示、引导和复制提示词。
